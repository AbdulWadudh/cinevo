# Release v0.1.0

**Date:** 2026-10-28

### Added

**Restore the original Cinevo details page as a Classic layout and make it the shipped default; the Back pill returns home.** ([TASK-3](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-3-classic-detail-layout.md) · 9e9df65)

The original Cinevo details page returns as the Classic layout: full-width player, then title, meta, genres, overview, actions, seasons, cast, collection and More Like This, rebuilt from HEAD's markup on the shared detail module. Classic is now the shipped default and listed first in the studio picker; the Back pill routes to `/` instead of history.

**Prime-style hover preview on poster cards: a spring pop-out panel with backdrop, meta, genres and cast portraits.** ([TASK-4](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-4-hover-preview-card.md) · 4ab62a2)

One shared `TitleHoverCard` now gives Cinevo's poster cards a Prime-style preview: after a 450ms rest on a fine pointer at 900px and up, a spring panel pops out of the card with the backdrop, score, synopsis, certificate, runtime or season count, genre chips and four cast portraits, plus Play, Trailer and More info. It reuses `getTitlePreviewAction` (cached per title), hit-tests the pointer before closing so reaching for the panel keeps it open, and dismisses on scroll, resize, pointer-down or leave. The old inline Netflix panel in `MediaCarousel` was replaced by it, and `GenreSection` and `SimilarTitles` were wrapped too; clones keep their own card behaviour.

**Two independent Studio options: an always-on eaten poster edge on home cards and the real CardSwap as the hero.** ([TASK-9](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-9-studio-card-effects.md) · 998ee48)

Two independent Studio axes now drive the home cards and the hero. Card effect adds an always-on, screen-blended decay border to the home rows, genre rail, Continue Watching, Daily Five, cast, More Like This and person Known For, with a 1–12px ring slider; Hero carousel swaps the hero banner for the ReactBits CardSwap deck (94% width, landscape, 50px stack distance, persisted Card-distance control). Both persist through the cookie and SiteTheme with migrations; the hero is full 100dvh and the mobile custom scrollbar is hidden.

### Changed

**Three switchable Cinevo details layouts — Stage, Dossier, Console — with a studio picker and a published default.** ([TASK-1](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-1-detail-layouts.md) · ce5fdba)

Replaced the Cinevo details page with three complete layouts — Stage, Dossier and Console — behind a third theme axis (`detailLayout`: trusted cookie `l` → `SiteTheme.detailLayout` → `stage`). Theme Studio gains a Details page picker and admins publish the layout with the palette. The three layouts share one props/format contract, reuse the existing player, season, cast and collection components, and surface the appended TMDB file (certificate, director/writers, budget/box office, networks, keywords, stills, IMDb link). Six ReactBits registry components were vendored under `src/components/reactbits/` and retokenized to the theme's CSS variables.

**Upgrade the kit to v1.1.0, clear the lint errors, trim AGENTS.md and SKILL.md** ([TASK-101](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-101-upgrade-agent-kit.md) · f942716)

Upgraded the installed agent-kit to v1.1.0 and cleared the rows that upgrade
left red. The 24 pre-existing lint errors are gone via types on the TMDB payloads and
behaviour-preserving React fixes; `AGENTS.md` is cut from 17,585 to 8,800 characters with the
product rules moved into six domain files behind `rules/INDEX.md`; `SKILL.md` is trimmed under
its own 10,000-char cap; both githooks are executable.

**Upgrade the kit to v1.3.0, hand-merging the rows the pull skips** ([TASK-104](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-104-upgrade-agent-kit.md) · d3249b4)

Pulled agent-kit v1.3.0 over v1.1.0: 33 machinery rows written, the `.counter`
file pruned, and the six rows the pull skipped (`SKILL.md`, `rules/INDEX.md`, `AGENTS.md`,
`tasks/INDEX.md`, `logs/INDEX.md`) hand-merged so the Cinevo rules and both length caps survive.
The kit now derives the five newest closes in `start` instead of storing them, and writes two
files per close instead of four.

**Tighten Dossier, fold Console's Story into its rail, and fit Stage's player in one viewport over stills.** ([TASK-2](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-2-detail-layout-polish.md) · d62787a)

Dossier's masthead is compact (page top 6.25rem, 4rem title, tighter columns). Console loses its Story tab; tagline, overview, genres and keywords sit under the name card and `?view=story` falls back to Cast/Episodes. Stage is a two-column hero over a full-height backdrop that cross-fades backdrop and TMDB stills every 7s; the Frames strip is gone and the player clears a 768px viewport.

**Cast and Known For cards get hover previews with carousels and skeletons; wishlist moves into the panel.** ([TASK-6](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-6-continue-watching-hover.md) · cdfb1ac)

Cast cards and the profile page's Known For grid now use the shared hover preview: actor biography, birthday, birthplace, known-for titles and a profile link. Both panels show match-shaped skeletons while the action resolves, and their Cast and Known For rows are snap carousels with hover arrows. Title cards move the wishlist toggle into the panel and drop the inline Play/Trailer/heart controls where the panel covers them, while coarse pointers keep them. The close reverses the open toward the card origin over 260ms, and focus loss, window blur or tab hide dismiss the panel.

### Fixed

**Scope the dome container rule to the div the component now renders so /gallery is visible again.** ([TASK-102](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-102-gallery-route-blank.md) · ad9d0b9)

Restored `/gallery`. TASK-101's accessibility pass changed `DomeGallery`'s `<main>` container to a `<div>` but left the CSS selector `main.sphere-main`, so the dome's absolute full-height box no longer applied and the stage collapsed to zero height. Scoped the rule to `.sphere-main`; the dome, drag, auto-rotate and holographic reveal are back, verified in the browser before and after.

**Match the details-page loading skeleton to the active layout so the page no longer flashes a Classic-shaped placeholder.** ([TASK-5](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-5-detail-loading-skeleton.md) · a2a3911)

The watch route's loading fallback now reads the active theme and paints a skeleton shaped like the layout that follows: Classic's player-then-title, Stage's full-height hero with the copy beside the player, Dossier's masthead plus poster rail, Console's player/control grid, and a backdrop hero for the clone experiences. It covers only the first viewport, and each shape breaks where its layout's CSS does (1100/901/1101px), so navigation no longer shows one generic placeholder that jumps when the real page arrives.

### Removed

**Drop the parallel project changelog; agent-kit change cards are the only record.** ([TASK-103](https://github.com/AbdulWadudh/cinevo/blob/v0.1.0/.agent-kit/tasks/archive/2026-10/2026-10-28-TASK-103-remove-project-changelog.md) · b73de19)

Removed `CHANGELOG.md`; agent-kit already writes one change card per task under `.agent-kit/logs/MM-YYYY/`, and its own selftest states there is no accumulating changelog. The two `AGENTS.md` references were the only live consumers: the start-order step now points at `agent-kit start` and the logs index, and the always-update rule keeps only `README.md`.
